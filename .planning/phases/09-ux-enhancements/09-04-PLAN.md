|----------|-------------|
| GET /api/sources response → sources state | Backend-provided strings rendered as button text — no HTML injection risk; React escapes string content |
| activeFilter → submit() → POST body | User-selected policy title or null crosses to backend |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-08 | Information Disclosure | sources state rendered as button labels | accept | Strings come from authenticated GET /api/sources (T-09-01 guards endpoint); React text nodes escape HTML — no XSS vector |
| T-09-09 | Spoofing | Crafted source_filter value in POST body | accept | Values originate from backend-provided list; even if a user crafts an arbitrary string, backend uses typed MatchValue — no injection (T-09-02 accepted same threat at backend layer) |
