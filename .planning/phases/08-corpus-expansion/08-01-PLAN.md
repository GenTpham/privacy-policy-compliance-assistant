**Text extraction functions:**

`extract_pdf(filepath: Path) -> str`:
- Open with `PdfReader(filepath)`
- If `reader.is_encrypted`: raise `ValueError(f"PDF is encrypted: {filepath.name}. Decrypt the file before ingestion.")`
- Extract text from all pages: `page.extract_text() or ""` for each page
- Join pages with `"\n\n"`
- Strip the result; if empty string: raise `ValueError("No text extracted — PDF may be scanned/image-based or encrypted. OCR is not supported.")`
- Return the text blob

`extract_txt(filepath: Path) -> str`:
- Try `filepath.read_text(encoding="utf-8")`
- On `UnicodeDecodeError`: try `filepath.read_text(encoding="latin-1")`
- Strip the result; if empty string: raise `ValueError(f"TXT file is empty: {filepath.name}")`
- Return the text

**Embed batch (local copy — does NOT import from ingest.py):**
```python
async def embed_batch(
    openrouter: AsyncOpenAI,
    texts: list[str],
    retries: int = 5,
) -> list[list[float]]:
    for attempt in range(retries):
        try:
            resp = await openrouter.embeddings.create(
                model=EMBED_MODEL, input=texts, encoding_format="float"
            )
            return [item.embedding for item in sorted(resp.data, key=lambda x: x.index)]
        except Exception as exc:
            err_str = str(exc).lower()
            is_rate_limit = "429" in err_str or "rate limit" in err_str
            if is_rate_limit and attempt < retries - 1:
                wait = 2 ** attempt
                print(f"[rate_limit] 429 on attempt {attempt + 1}/{retries} — sleeping {wait}s")
                await asyncio.sleep(wait)
                continue
            raise RuntimeError(f"embed_batch failed after {retries} retries: {exc}") from exc
    raise RuntimeError(f"embed_batch failed after {retries} retries")
```

Steps inside `ingest_doc`:
1. Detect file type from `filepath.suffix.lower()`:
   - `.pdf` → call `extract_pdf(filepath)`, set `file_type = "pdf"`
   - `.txt` → call `extract_txt(filepath)`, set `file_type = "txt"`
   - anything else → `raise ValueError(f"Unsupported file type: {filepath.suffix!r}. Only .pdf and .txt are supported.")`
2. `passage_id = filepath.stem`
3. Call `chunk_passage(text, passage_id=passage_id, title=title, source_doc=title)`
4. Print `[ingest_doc] Extracted {len(chunks)} chunks from {filepath.name}`
5. Compute UUID5 point IDs for all chunks:
   ```python
   all_ids = [
       str(uuid.uuid5(uuid.NAMESPACE_DNS, f"{c.passage_id}:{c.chunk_index}"))
       for c in chunks
   ]
   ```
6. Initialize clients: `openrouter, qdrant = _make_clients()`
7. Retrieve existing IDs from Qdrant:
   ```python
   found = await qdrant.retrieve(
       collection_name=COLLECTION_NAME,
       ids=all_ids,
       with_payload=False,
       with_vectors=False,
   )
   existing = {str(r.id) for r in found}
   ```
8. If `dry_run`:
   ```python
   new_count = len(all_ids) - len(existing)
   print(f"[dry_run] Would ingest {new_count} chunks ({len(existing)} already indexed — would skip)")
   return
   ```
9. Filter to new-only chunks (pairs of chunk + id not in `existing`):
   ```python
   new_pairs = [(c, uid) for c, uid in zip(chunks, all_ids) if uid not in existing]
   ```
10. If `not new_pairs`: print `[ingest_doc] All chunks already indexed — nothing to do.` and return.
11. Probe dim and ensure collection:
    ```python
    dim = await probe_embedding_dim(openrouter)
    await ensure_collection(qdrant, dim)
    ```
12. Batch embed and upsert (same BATCH_SIZE=50 / BATCH_SLEEP_SECONDS=3 pattern as ingest.py):
    - For each batch: embed texts → build PointStruct list with full payload including `file_type` → upsert with `wait=True` → assert `result.status == UpdateStatus.COMPLETED` else raise RuntimeError → sleep `BATCH_SLEEP_SECONDS`
    - Payload per point:
      ```python
      {
          "title": title,
          "source_doc": title,
          "passage_id": chunk.passage_id,
          "text": chunk.text,
          "chunk_index": chunk.chunk_index,
          "token_count": chunk.token_count,
          "file_type": file_type,
      }
      ```
13. Print summary: `[ingest_doc] Done. Upserted {len(new_pairs)} new chunks ({len(existing)} skipped — already indexed).`
