Create `frontend/Dockerfile` (build context is `frontend/` — all COPY paths are relative to that directory):

```dockerfile
# Stage 1: Build — node:20-alpine produces dist/
FROM node:20-alpine AS builder

# VITE_API_URL baked into the JS bundle at npm run build time (D-03)
# Default is /api — correct for Docker Compose (nginx proxies /api/* to backend)
# Override at build time: docker build --build-arg VITE_API_URL=http://localhost:8000
ARG VITE_API_URL=/api
ENV VITE_API_URL=${VITE_API_URL}

WORKDIR /app

# Copy dependency manifests first — Docker layer cache optimization (mirrors backend/Dockerfile pattern)
COPY package.json package-lock.json ./
RUN npm ci

# Copy application source after dependencies
COPY . .
RUN npm run build

# Stage 2: Serve — nginx:alpine serves the static bundle
FROM nginx:alpine

# Copy built assets from Stage 1
COPY --from=builder /app/dist /usr/share/nginx/html

# Copy nginx reverse proxy config
COPY nginx.conf /etc/nginx/conf.d/default.conf

EXPOSE 80
# nginx runs as the default CMD — no explicit CMD override needed
```

Key decisions:
- `npm ci` (not `npm install`) — reproducible installs from package-lock.json
- `ARG VITE_API_URL=/api` before `RUN npm run build` so Vite's import.meta.env.VITE_API_URL replacement runs at build time
- Two-stage keeps the production image small (no Node.js runtime in the nginx image)
- No CMD line needed — nginx:alpine default CMD is `nginx -g 'daemon off;'`

  <action>
Create `frontend/nginx.conf`:

```nginx
server {
    listen 80;
    server_name _;

    # Gzip static assets
    gzip on;
    gzip_types text/plain text/css application/javascript application/json;

    # Proxy /api/* → FastAPI backend (D-02: eliminates CORS entirely)
    location /api/ {
        proxy_pass         http://backend:8000;
        proxy_http_version 1.1;
        proxy_set_header   Host              $host;
        proxy_set_header   X-Real-IP         $remote_addr;
        proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;

        # SSE streaming: disable buffering so tokens reach the browser immediately
        # Without this, nginx holds SSE chunks until its buffer fills — chat UI appears frozen
        proxy_buffering    off;
        proxy_cache        off;
        chunked_transfer_encoding on;
    }

    # Proxy /auth/* → FastAPI backend (login, refresh, logout endpoints)
    location /auth/ {
        proxy_pass         http://backend:8000;
        proxy_http_version 1.1;
        proxy_set_header   Host              $host;
        proxy_set_header   X-Real-IP         $remote_addr;
        proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
    }

    # Serve React SPA static files
    location / {
        root  /usr/share/nginx/html;
        index index.html;
        # SPA routing: deep links and page refreshes fall through to index.html
        # Without this, refreshing /chat returns 404 from nginx
        try_files $uri $uri/ /index.html;

        # Cache-bust: Vite outputs JS/CSS with content hashes — cache forever
        location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2)$ {
            expires 1y;
            add_header Cache-Control "public, immutable";
        }
    }
}
```

Critical requirements:
- `proxy_buffering off` on `/api/` is mandatory — the `/api/chat` SSE endpoint streams tokens; nginx default buffering holds them until the buffer is full, making the chat UI appear frozen
- `try_files $uri $uri/ /index.html` is required — React Router manages routes client-side; without this fallback, nginx returns 404 on hard refresh at any non-root URL
- `proxy_pass http://backend:8000` uses Docker Compose service name `backend` — works because frontend and backend share the default bridge network
- Both `/api/` and `/auth/` must be proxied (vite.config.ts confirms both are needed)

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → nginx (port 80) | All user traffic enters here; nginx is the only public-facing port |
| nginx → backend:8000 | Internal Docker network; nginx forwards /api/ and /auth/ requests |
| backend → qdrant:6333 | Internal Docker network; backend queries vector store |
| Host → Docker daemon | docker compose up / build commands run with host user permissions |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Spoofing | nginx proxy — X-Forwarded-For header | mitigate | Set `proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for` and `X-Real-IP $remote_addr` in nginx.conf so backend can log real client IPs; prevents IP spoofing in logs |
| T-06-02 | Tampering | frontend/Dockerfile build — VITE_API_URL build ARG | accept | ARG default is `/api` (relative path); no secret values in build args; attacker cannot inject via docker-compose.yml without host access |
| T-06-03 | Information Disclosure | nginx serves dist/ static files | mitigate | Cache headers only on hashed-filename assets (immutable); index.html gets no Cache-Control so auth state changes are always fetched fresh |
| T-06-04 | Denial of Service | nginx proxy to backend — large SSE connections | accept | Single-user dev/demo deployment; no rate limiting needed at v1; revisit in v2 with nginx `limit_req` |
| T-06-05 | Elevation of Privilege | Docker socket exposure | mitigate | Services run as default non-root users (nginx:alpine and node:20-alpine use non-root by default); no privileged: true in docker-compose.yml |
| T-06-06 | Spoofing | phoenix service accessible on observability profile | mitigate | `profiles: [observability]` ensures phoenix only starts when explicitly requested; phoenix port 6006 is NOT exposed in default stack |
</threat_model>
